# Є-Гідність — безпечний український месенджер (демо)
1. Завантажте вміст у GitHub-репозиторій (гілка `main`).
2. Вкладка **Actions → Build APK** запуститься сама (або Run workflow).
3. Після завершення: внизу сторінки запуску, **Artifacts → egidnist-apk**. Для більшості телефонів підійде `app-arm64-v8a-release.apk`.
